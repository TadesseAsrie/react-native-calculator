# 🧮 React Native Calculator

A modern, professional, and fully functional Calculator mobile application built with **React Native, Expo, and TypeScript**.

The app provides both Standard and Scientific calculator modes with calculation history, memory functions, themes, angle modes, and local data persistence.

---

## ✨ Features

### 🧮 Standard Calculator

* Addition
* Subtraction
* Multiplication
* Division
* Percentage
* Decimal calculations
* Positive / Negative
* Parentheses
* Backspace
* Clear
* Mathematical operator precedence

### 🔬 Scientific Calculator

* `sin`
* `cos`
* `tan`
* `sin⁻¹`
* `cos⁻¹`
* `tan⁻¹`
* `sinh`
* `cosh`
* `tanh`
* `log`
* `ln`
* `log₂`
* Square root
* Cube root
* Square
* Cube
* Power
* Reciprocal
* Factorial
* `π`
* `e`
* `10ˣ`
* `eˣ`
* `mod`
* `abs`
* `floor`
* `ceil`

### 📐 Angle Modes

* Degrees (DEG)
* Radians (RAD)

### 💾 Calculation History

* Automatically save calculations
* View previous calculations
* Reuse previous calculations
* Delete individual calculations
* Clear all history
* Persistent history after restarting the app

### 🧠 Memory Functions

* MC — Memory Clear
* MR — Memory Recall
* M+ — Memory Add
* M− — Memory Subtract
* MS — Memory Store

### 🎨 Appearance

* Light mode
* Dark mode

* Modern responsive interface
* Smooth animations
* Touch feedback

### ⚙️ Settings

* Theme selection
* Angle mode
* Haptic feedback
* Sound preferences
* Clear history
* About section
